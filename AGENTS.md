# Proaqua Website — Arbeitsregeln

## WICHTIG: Git-Regeln

- **NIEMALS pushen.** Kein `git push`, unter keinen Umständen, außer Giampiero sagt es ausdrücklich ("pushe jetzt" o.ä.).
- Wir arbeiten **ausschließlich lokal** an diesem Projekt.
- Lokale Commits sind erlaubt und erwünscht, um Arbeitsstände zu sichern.
- Remote: https://github.com/Proaqua/proaqua-website (Branch `main`)

## WICHTIG: Gemeinsames Arbeitsgedächtnis

- **Lies zu Beginn jeder Session die Datei `MEMORY.md`** — dort steht der aktuelle Arbeitsstand.
- **Trage nach jedem abgeschlossenen Arbeitsschritt einen Eintrag ins Arbeitslog in `MEMORY.md` ein.** An diesem Projekt arbeiten mehrere KI-Assistenten (Claude, Codex) abwechselnd — die Datei ist die gemeinsame Übergabe.

## Projekt

- Statische Website (Netlify-Deployment via `netlify.toml`)
- Hauptdatei: `index.html` (sehr groß, ~3,2 MB — vorsichtig editieren, gezielt mit Suchen/Ersetzen arbeiten statt komplett neu schreiben)
- Weitere Dateien: `assets/`, `robots.txt`, `sitemap.xml`
